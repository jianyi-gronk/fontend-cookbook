# 1. SEO 优化

- SEO（ Search Engine Optimization，搜索引擎优化 ）是一种通过 技术优化、内容优化 和 外链优化，提升网站在 Google、bing、百度 等搜索引擎的 自然搜索结果 中的排名，从而获取免费、持续的高质量流量的策略

## 1.1 技术优化

- 规范网页声明
  - 使用 \<link rel="canonical" href="标准网址" \/> 明确告诉 Google 哪个 URL 是主要版本，集中权重，避免重复内容分流排名
- 网站性能优化
  - Google 使用 Core Web Vitals（ 核心网页指标 ）作为排名依据
    - LCP：最大内容绘制，页面主要内容加载速度，压缩图片、启用 CDN、优化服务器响应时间
    - INP：与下一次绘制的交互，页面响应交互的延迟，减少 JavaScript 执行时间、拆分长任务
    - CLS：累计布局偏移，页面视觉稳定性，为图片/视频预留固定宽高空间，避免广告弹窗突然插入
- 移动端友好
  - 移动优先索引：Google 主要使用移动版网页内容进行索引和排名
  - 适配要求
    - 响应式设计，同一 URL 在不同设备自适应
    - 移动端字号适中，无需缩放即可阅读
    - 可点击元素间距合理，避免误触

## 1.2 内容优化

- 关键词策略
  - 核心关键词：网站主推的服务/产品词（ 如 “香港 网站建设” ），布局在首页、核心产品页
  - 长尾关键词：搜索量小但意图精准的短语（ 如 “WordPress 网站迁移教程 2026” ），布局在博客文章、问答页
  - 搜索意图匹配：内容形式需匹配关键词意图
    - 信息型（ 搜 “怎么...” ）：提供教程、攻略
    - 商业型（ 搜 “...推荐” ）：提供对比评测、排行榜
    - 交易型（ 搜 “...价格” ）：提供产品详情、购买入口
- 页面内优化要素
  - 标题标签 \<title\>：包含核心关键词，长度约 50-60 字符，格式建议：主要关键词 - 品牌名
  - 元描述 \<meta description\>：虽非直接排名因素，但直接影响点击率（ CTR ），应包含关键词并引导点击
  - 标题层级（ H1-H6 ）：每个页面仅一个 H1（包含主关键词），H2/H3 用于结构化分段
  - 图片 Alt 属性：描述图片内容并自然包含关键词，既利于图片搜索 SEO，也利于视障用户体验
  - 内部链接锚文本 链接到其他页面时，用描述性文字而非“点击这里”，帮助 Google 理解目标页主题
- 内容质量标准（ E-E-A-T ）
  - Google 质量评估员指南强调 E-E-A-T
    - 经验（ Experience ）：作者是否有亲身实践经验
    - 专业（ Expertise ）：内容是否专业、准确
    - 权威（ Authoritativeness ）：作者/网站是否是该领域的公认权威
    - 信任（ Trustworthiness ）：网站是否安全（ HTTPS ）、联系方式是否透明

## 1.3 外链优化

- 外链是 Google 排名算法中权重最高的因素之一，每条外链相当于其他网站对你的 “投票”
- 外链质量判定标准
  - 相关性：来自同行业、同主题网站的链接价值更高
  - 权威性：来自政府、教育、知名媒体或行业头部网站的链接价值极高
  - 自然性：带有 nofollow 或 ugc 属性的链接虽不传递权重，但依然能带来流量和品牌曝光
- 高质量外链获取方法（白帽手法）
  - 创建“链接诱饵”：发布深度行业报告、独家数据、免费工具或信息图，其他站长会自发引用
  - 客座博客：在行业权威网站投稿高质量文章，换取作者简介中的一条链接
  - 替换失效链接：查找同行网站中已失效的外链，主动联系站长建议换成你的相关优质内容
  - 品牌提及转化：监控网上提到你品牌但未加链接的地方，礼貌请求对方添加链接。
- 避坑指南
  - 严禁购买链接：违反 Google 垃圾内容政策，可能遭致人工处罚或算法降权
  - 避免链接农场：不要参与大规模互链、低质量目录提交

# 2. SEO 评估指标

- 评估 SEO 收益需要监控三类指标，即 过程指标 → 目标指标 → 业务指标

## 2.1 过程指标

- 过程指标 用于 监测和优化 SEO 工作本身的有效性，它们反映了搜索引擎与网站互动的基础健康度，是达成最终目标的前提
- 反向链接数量与质量
  - 指向你网站的外部链接的数量，以及这些链接来源网站本身的权威性
  - 高质量的反向链接仍然是搜索引擎最信任的“投票”机制，是提升域名权威性和排名的核心驱动力
  - 通过 Google Search Console 的 “链接” 报告，或第三方外链分析工具（ 如 Ahrefs, Majestic ）
- 引用域数量
  - 有多少个独立的域名链接到你的网站
  - 自 100 个不同域名的各 1 个链接，通常比来自 1 个域名的 100 个链接更有价值，它代表了更广泛的认可
- 核心网页指标
  - 由 Google 提出的一组量化用户体验的指标，主要包括
    - LCP：衡量加载速度。理想时间应在 2.5 秒以内
    - INP：衡量交互性。理想时间应在 200 毫秒以内
    - CLS：衡量视觉稳定性。理想分数应低于 0.1
  - 通过 Google Search Console 的 核心网页指标 报告、PageSpeed Insights 查看
  - 它们是 Google 的直接排名因素，并且严重影响用户的停留与转化
- 已编入索引页面数
  - 网站有多少个页面被搜索引擎存入索引库
  - 这是排名的前提，如果页面未被收录，就不可能获得流量
  - 通过  `site:yourdomain.com`  指令进行粗略估算，或在 Google Search Console 的 “索引” 版块查看精确数字
- 收录率
  - （ 已索引页面数 / 网站总页面数 ）x 100%
  - 高收录率说明网站结构良好，所有重要页面都被发现；低收录率则表明可能存在重复内容、低质量页面或技术问题导致页面无法被收录
- 爬虫抓取统计
  - 搜索引擎蜘蛛访问你网站的频率、抓取的页面数以及抓取时是否遇到错误。
  - 抓取频率高通常意味着网站更新频繁、权威性高；抓取错误则需要及时修复，以免影响收录
  - 通过 Google Search Console 中的 “抓取统计信息” 和 “爬虫抓取” 部分查看

## 2.2 目标指标

- 目标指标 是 SEO 工作带来的直接成果，它们清晰地展示了网站在搜索引擎中的能见度和吸引力
- 关键词排名位置
  - 目标关键词在搜索结果中的平均排名
  - 排名越高，通常获得的点击和流量就越多，排名趋势可以衡量 SEO 策略是否有效
  - 通过 Google Search Console 的 “搜索效果” 报告，或第三方 SEO 工具（ 如 SERPROBOT，Small SEO Tools 等 ）查看
- 展示次数
  - 网站在所有包含你关键词的搜索结果中，实际被用户看到的展示次数
  - 即使排名很高，也可能因为竞争对手的富媒体摘要（ 如精选片段、知识图谱 ）占据了大部分展示空间，这个指标帮助了解真正的可见度
  - 通过 Google Search Console 的“搜索效果” 报告查看
- 点击率
  - 即搜索结果被展示后，用户点击它的比例，（ 点击次数 / 展示次数 ）x 100%
  - 高点击率意味着 标题标签 和 元描述 足够吸引人，优化这两个元素可以有效提升 CTR，即使排名不变也能带来更多流量
  - 通过 Google Search Console 的“搜索效果” 报告查看
- 自然搜索流量
  - 通过搜索引擎的自然搜索结果（ 非广告 ）访问你网站的用户数量和会话次数
  - 通过 Google Analytics 等网站分析工具
  - 这是 SEO 工作的核心成果，直接反映了 SEO 带来的价值
- 平均停留时长
  - 用户通过搜索结果进入你的网站后，平均每次会话在网站上停留的时间
  - 较长的停留时间通常暗示内容质量高，符合用户搜索意图，搜索引擎会将其视为积极信号
  - 通过 Google Analytics 查看
- 跳出率
  - 仅浏览了一个页面便离开网站的访问次数占总访问次数的百分比
  - 高跳出率可能意味着页面内容不相关、用户体验差或未能满足用户需求。但需结合上下文分析，例如博客文章的跳出率天然较高
  - 通过 Google Analytics 查看

## 2.3 业务指标

- 业务指标 用于衡量 SEO 工作带来的最终业务收益
- 转化数
  - 由自然搜索流量直接产生的潜在客户数量、订单数量 或 营业收入
  - 代表了流量带来的总收益，转换数高代表 SEO 的收益大
- 转化率
  - 通过自然搜索流量完成目标动作（ 如 购买、注册、下载 ）的用户百分比
  - 代表了流量的质量，高转化率意味着 SEO 吸引了精准的目标用户，并满足了他们的需求
